[NOTE] The font carries no glyph names
    what:  Its post table is format 3.0, so glyphs have no names and tools refer to them as glyph00131 or gid131. The app handles this by using glyph IDs, but font editors will show unhelpful names.
    fix:   Nothing required. To get readable names, re-export with post format 2.0 ('keep glyph names' in most editors).
